# 行列之间 · Determinant Lab

可自由选择操作的行列式学习网站，包含 78 道练习、精确数学运算、过程动画和可关闭的交互音效。

**在线使用：[GitHub Pages](https://gaygay-lab.github.io/determinant-lab/)**

## 功能

- 78 题，覆盖 2–5 阶和 10 类结构：求和差分、基础变换、三对角递推、分块结构、范德蒙、秩一更新、三角与逆序、线性相关、拆分辨析、齐次范德蒙。
- 任选目标、来源和倍数，使用行列倍加、汇总、交换、常数倍乘、转置与符合条件时提取公因子。左键选择目标，右键选择来源；可提取时点击按钮即可执行。
- 题库默认收起，完成一关后自动进入下一关。快捷键：`T` 重置、`A` 汇入第一列、`R/C` 切换行列、`M` 倍加、`X` 提取公因子、`S` 交换、`V` 转置。
- 连续 60 秒没有完成时，会出现黄色的最短参考演示；参考路线不会替用户自动执行。
- 预览结果、撤销、重做、分题保存路线。无需按唯一顺序解题。
- 零块压缩、非零排列项计数和可读结构识别。
- 九类 Web Audio 合成音效，提供静音、音量和独立试听。
- 纯静态 HTML/CSS/JavaScript，无后端、账户或第三方运行时依赖。

## 使用与开发

下载仓库后直接打开 `index.html`，或在仓库根目录启动任意静态文件服务器，例如：

```sh
python -m http.server 8000
```

然后打开 `http://localhost:8000`。文件全部使用相对路径，可部署到 GitHub Pages 的项目子目录。

```sh
node tests/engine-test.cjs
node tests/symbolic-test.cjs
node tests/bank-test.cjs
```

测试无需安装 npm 依赖。

## 游戏体验

每个新浏览器会话都会先播放一个可跳过的开屏演示，然后进入第一关教程。开屏演示直接使用在线实验台的白灰黑矩阵视觉。前 10 关按“倍加、交换、倍乘、提取、汇入、转置、列操作、三阶消元、零列、唯一排列”逐步放权。

## 数学与范围

第 1 题保留含 x 的符号矩阵，其余 77 题为数值练习。倍乘、交换和提取因子都会同步更新外因子，保证原始行列式的值不变。提取 x 使用多项式系数操作，在 x=0 时也成立。

三对角题提供 D₀、D₁、Dₙ 递推、闭式与数值样本；拉普拉斯模式逐项展示余子式，定义模式逐步走排列与逆序数。每题演示独立于玩家路线，支持暂停、单步、重播和调速。参考路线只展示一种解法。

学习记录和声音偏好只保存在访问者自己的浏览器 `localStorage` 中。此项目不发送这些记录到服务器。
