# Game UX sources

These are focused public references used to shape this skill. They are source links and concise notes, not copied manuals.

## Game feel

[ronniebasak/game-feel-skill — Game Feel](https://github.com/ronniebasak/game-feel-skill/blob/main/skills/game-feel/SKILL.md)

- Useful model: Input, Response, Context, Polish, Metaphor, Rules.
- The source emphasizes fast perceptible feedback, predictable state changes, repeatable actions, and layered feedback for important actions.
- Transfer to determinant-lab: highlight the target immediately, then animate blocks and play a quiet sound; make errors reversible and explainable.

## Onboarding

[Roblox Creator Docs — Onboarding](https://github.com/Roblox/creator-docs/blob/main/content/en-us/production/game-design/onboarding.md)

- Useful goals: teach essentials, get to the fun quickly, and leave the player wanting more.
- Transfer to determinant-lab: show one satisfying complete transformation, then let the player repeat one action before revealing the rest of the controls. Keep the demo skippable.

## Game UX checklist

[tinh2/skills-hub-registry — game-ux](https://github.com/tinh2/skills-hub-registry/blob/main/ux/game-ux/SKILL.md)

- Useful checklist: every action needs input, immediate feedback, confirmation, and cancel/return behavior; teach by doing; keep help contextual and replayable.
- Transfer to determinant-lab: define each row/column action as target → source → automatic coefficient → visible motion → undo path.

## Local synthesis

The skill's suggested first-ten sequence and determinant-specific principles are design recommendations for this project. They are not claims about the source authors' products or a universal game-design law.
